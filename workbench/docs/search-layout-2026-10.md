# 搜索弹层与导航尺寸修复

全局搜索面板此前只有背景样式，缺少固定定位、默认隐藏和打开状态的布局。面板参与正常文档流，输入框聚焦后会将整个文档向下滚动，导致主工作区上移、下方出现大片空白。现已将搜索设为视口内的固定弹层，结果列表独立滚动，并在打开、关闭时避免焦点改变滚动位置。

实际数据模式下统一了各页面的侧栏宽度、导航项高度、分组和底部区域间距。桌面侧栏 240px，中等窗口 205px，手机或主动折叠时 65px；切换总览、记忆、灵感等页面不再改变尺寸。历史参考图演示保留各页原有几何布局。

验证仅使用合成数据：

- 1654×951、1462×727、1366×900、1024×768、390×844，共 40 组页面/窗口检查。
- 搜索弹层保持在视口内，打开/关闭后主区位置不变，零结果有明确提示，选择结果能切换页面。
- 实际模式侧栏在切页和折叠状态下尺寸一致。
- 演示模式额外检查 8 页搜索；脚本错误 0。
- 现有实际模式 24 组布局与交互检查通过；TypeScript 检查通过。服务端隔离回归 97 通过、2 项环境相关跳过。

```sh
PLAYWRIGHT_MODULE=/path/to/playwright CHROME_PATH=/path/to/chrome \
  node workbench/scripts/verify-search-layout.cjs
```

仅修改静态 UI 资源和资源版本号；保留实例自己的配置与额外入口。没有数据库、认证或 API 行为变更。
